# DeshiPay

**One link to receive payments, donations and support.** DeshiPay gives your shop, your work or your
cause a payment page: customers scan a live Bangla QR with the amount already in it, or copy your
bKash, Nagad or bank details. No app for them to install, nothing for you to integrate.

Live: **<https://deshipay.netlify.app>**

The **Bangla QR is the headline feature**: the page rewrites the QR you already own so the amount is
ready before the customer scans. Wallet numbers and bank details sit beside it for people who would
rather copy and send. Use one page for a sale, an invoice, a tip, a donation or support — it is a
complete way to receive money, not just a QR generator.

DeshiPay is *not* a payment processor: it never handles, holds or confirms money. Customers pay from
their own banking app, straight to the account in the QR.

The payload engine behind the site is a separate, zero-dependency library project:
**[deshiQR](https://github.com/hello2himel/deshiQR)** — npm [`deshiqr`](https://www.npmjs.com/package/deshiqr),
PyPI [`deshiqr`](https://pypi.org/project/deshiqr/), browser bundle on GitHub Pages. This repo vendors
its browser bundle (`site/public/vendor/deshiqr.global.js`, committed) so the site deploys without the
library toolchain.

## Who it is for

- Shops and small businesses taking payments at the counter or online.
- Freelancers and studios sending a client a link to pay an invoice.
- Creators and communities collecting tips, support or donations.
- Causes and campaigns receiving contributions with a real QR and copyable details.

## What's here

- **Landing** (`/`) with a live, scannable payment-page demo (real QR, typed amount).
- **Sign in / sign up** (`/login`) on Supabase Auth; the dashboard (`/app`) has a short setup wizard,
  then the page editor (link/username, QR, wallet & bank details, theme, share).
- **Customer pages** (`/<username>`): QR / Wallet / Bank methods, amount + quick amounts, amount-bearing
  QR generated in the visitor's browser, Save QR image, "How to pay".
- **Offline mode**: if Supabase is paused or unreachable, the site still builds a page — no account —
  and downloads it as one self-contained HTML file you can host anywhere.
- **10 colour themes** with matching dark mode (Emerald is the default), all surfaces derived from the
  accent. Themes are generated by `site/scripts/gen-themes.js` into `site/public/css/themes.css`, and a
  **light/dark toggle in the nav** remembers the visitor's choice.
- **Legal + support** pages (`/terms`, `/privacy`, `/contact`), a generated-free static sitemap and a
  shared footer.

## Run it locally

No dependencies are needed for the site itself (Node >= 20):

```sh
node site/scripts/dev-server.js      # http://localhost:8888 — mimics Netlify routing
node site/tests/qr.test.js           # payload adapter + page wiring (30 checks)
node site/tests/export.test.js       # standalone export / escaping (18 checks)
node site/scripts/gen-themes.js      # regenerate site/public/css/themes.css (commit the result)
```

Sign-in and publishing need a Supabase project; without one the site runs in offline mode. To point it
at a project, create `site/public/js/config.js` from the values Netlify would inject (see
[`docs/website.md`](./docs/website.md)), or set `SUPABASE_URL` / `SUPABASE_ANON_KEY` and run
`node site/scripts/build-config.js`.

The browser e2e suite needs Chromium + `puppeteer-core`; see
[`site/tests/e2e/run.js`](./site/tests/e2e/run.js).

## Deploy

Netlify reads the repo-root [`netlify.toml`](./netlify.toml): base `site`, publish `public`, build
command `node scripts/build-config.js`, which writes `site/public/js/config.js` from the
`SUPABASE_URL` and `SUPABASE_ANON_KEY` environment variables (optionally `GOOGLE_AUTH=true`).

1. Import this repo into Netlify, set the environment variables.
2. Connect the repo in Supabase's GitHub integration so pushes to `main` apply
   [`supabase/migrations/`](./supabase/migrations/), and add `https://deshipay.netlify.app/app` (plus
   `http://localhost:8888/app`) to the Auth redirect URLs.
3. Push. Netlify builds and deploys the static site.

Full steps, Supabase project settings-as-code, the offline/standalone flow and troubleshooting:
[`docs/website.md`](./docs/website.md).
