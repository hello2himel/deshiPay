deshiQR browser bundle

One file, no bundler, no build step: deshiqr.global.js exposes window.DeshiQR (payload + QR) and registers the <deshiqr-pay> element. The same package on npm is also available as an ESM import.

Library

<script src="deshiqr.global.js"></script>
<script>
  const payload = DeshiQR.withAmount(basePayload, 500);
  document.querySelector("#qr").innerHTML =
    DeshiQR.toSvg(DeshiQR.encode(payload), { margin: 4, scale: 8 });
</script>

This page derives a ৳500 payload from the synthetic DEMO STORE payload in docs/demo-payloads.md and renders it with the bundled QR encoder. Do not scan it — the account is fake.

Web component

The same file also gives you the amount-input panel; no separate script needed.

<deshiqr-pay payload="00020101021126…" title="Demo Store" presets="100,500,1000"></deshiqr-pay>

Where this file comes from

It is built from this repo (pnpm build) and published to GitHub Pages on every v* tag by .github/workflows/cdn.yml. The npm package deshiqr is also served by jsDelivr and unpkg. raw.githubusercontent.com cannot be used in a <script src> (it serves text/plain with nosniff), which is why this page exists.
